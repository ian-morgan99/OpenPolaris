## Why state:0?

The 286 response is the SP layer's **cached** state. It was
set by the last successful `sp_Gphoto_Init` (which ran for the
K-3 III at ~12:51 per the Mlog timestamps). Since then:
- `pgphoto` died
- The K-1 II replaced the K-3 III physically
- The SP layer's cached state was never refreshed because
  `sp_Gphoto_Init` can't run without pgphoto

So the gimbal sees:
- A K-1 II on the USB bus (lsusb)
- No manufacturer/model info (because pgphoto never identified it)
- `state:0` (cached "camera attached but not initialised" from K-3 III)

The K-1 II has not been "seen" by the SP layer as a camera
yet. The runtime is dead.
